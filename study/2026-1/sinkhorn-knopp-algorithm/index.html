Sinkhorn-Knopp Algorithm — 이중확률행렬부터 EPTQ의 L1 스케일 정규화까지

오늘 배운 것

Sinkhorn-Knopp 알고리즘을 세 층위로 나눠 정리했다.

  1. 고전 버전(1967): 임의의 양수 행렬을 doubly stochastic matrix(행/열 합이 모두 1)로 바꾸는, 행/열 정규화를 번갈아 반복하는 순수한 행렬 균형화 절차.
  2. 최적수송(OT) 버전(Cuturi, 2013): 엔트로피 정규화를 더한 최적수송 문제의 해가 “\(\mathrm{diag}(u)\,K\,\mathrm{diag}(v)\)” 형태를 갖는다는 걸 보이고, 그 스케일 벡터 \(u, v\)를 구하는 데 같은 반복 구조를 재사용한 것.
  3. EPTQ에서의 응용: 두 버전과 다른 목적(행/열 합=1이 아니라 행/열 L1 평균의 균일화)으로, 같은 “행 정규화 ↔ 열 정규화 교대” 구조를 가중치 행렬 스케일링에 재사용.

핵심은 세 가지가 전부 **“같은 반복 구조를, 다른 목적함수/제약에 적용”**한다는 점이다.

왜 중요한가 (맥락/동기)

EPTQ 논문(content/papers/2026-07-eptq-factored-e8-quantization/) 4.2절 Weight Scale Normalization에서 “Sinkhorn-Knopp 알고리즘의 반복 구조를 재사용한다"는 문장이 나오는데, Sinkhorn-Knopp 자체를 제대로 모르면 이 문장이 왜 성립하는지(그리고 무엇이 원래 알고리즘과 다른지) 판단할 수 없었다. 이 논문을 코드 기반으로 재현하려면 Algorithm 1(Iterative Weight Scaling)이 “진짜 Sinkhorn-Knopp"인지, 아니면 이름만 빌린 유사 알고리즘인지 구분하고 넘어가야 한다.

핵심 개념 정리

1. 고전 Sinkhorn-Knopp: Doubly Stochastic Matrix Scaling

Doubly stochastic matrix란 모든 원소가 0 이상이고, 모든 행의 합과 모든 열의 합이 각각 1인 정방행렬이다. 예를 들어 다음 행렬은 doubly stochastic 이다.

$$ P = \begin{bmatrix} 0.3 & 0.7 \\ 0.7 & 0.3 \end{bmatrix} $$

Sinkhorn-Knopp 정리(1967)는 “적절한 조건(비음수, 완전 지지 등)을 만족하는 양수 행렬 \(A\)는, 대각행렬 \(D_r, D_c\)를 곱해 \(P = D_r A D_c\) 형태로 doubly stochastic하게 만들 수 있다"는 것을 보장한다. 이 \(D_r, D_c\)를 찾는 절차가 다음 반복이다.

  1. 각 행의 합이 1이 되도록 행을 정규화한다.
  2. 각 행 정규화 결과에 대해, 각 열의 합이 1이 되도록 열을 정규화한다.
  3. 1~2를 수렴할 때까지 반복한다.

import numpy as np

def sinkhorn_knopp(A: np.ndarray, n_iter: int = 20, eps: float = 1e-12) -> np.ndarray:
    P = A.copy().astype(float)
    for _ in range(n_iter):
        P = P / P.sum(axis=1, keepdims=True).clip(min=eps)  # 행 합 = 1
        P = P / P.sum(axis=0, keepdims=True).clip(min=eps)  # 열 합 = 1
    return P

행을 정규화하면 열 합이 다시 흐트러지고, 열을 정규화하면 행 합이 다시 흐트러지지만, 이 두 조작을 번갈아 적용하면 행/열 합이 모두 1로 수렴한다 (Contraction mapping으로 선형 수렴이 증명되어 있다). 여기까지는 최적수송이나 엔트로피와 아무 관계가 없는, 순수한 행렬 균형화(matrix balancing) 문제다.

2. 최적수송(OT) + Entropic Regularization 버전 (Cuturi, 2013)

최적수송 문제는 “source 분포 \(r\)의 질량을 target 분포 \(c\)로 옮길 때, 이동 비용 행렬 \(M\)에 대해 총 비용을 최소화하는 수송계획 \(P\)를 찾는 문제"다(Wasserstein distance). 이걸 선형계획법(LP)으로 풀면 \(O(n^3 \log n)\) 이상이 걸려서, 대규모 데이터에는 비현실적이다.

Cuturi(2013)는 목적함수에 엔트로피 항을 더해 문제를 완화한다.

$$ \min_{P} \; \langle P, M \rangle - \lambda H(P) $$

(\(H(P)\)는 \(P\)의 엔트로피, \(\lambda\)는 정규화 강도.) 엔트로피 항은 “비용은 최소화하되, 수송계획이 지나치게 뾰족(sparse)해지지 않도록” 부드러움 제약을 준다. 라그랑주 승수법으로 이 문제를 풀면 해가 다음 형태를 갖는다는 것이 핵심 결과다.

$$ P = \mathrm{diag}(u)\, K \,\mathrm{diag}(v), \qquad K = e^{-\lambda M} $$

\(K\)는 Gibbs kernel로, 비용이 싼 위치(\(M\)이 작은 곳)일수록 값이 크다. 남은 문제는 \(P\)의 행 합이 \(r\), 열 합이 \(c\)가 되도록 스케일 벡터 \(u, v\)를 찾는 것인데, 이게 정확히 “marginal이 1이 아니라 \(r, c\)로 일반화된 Sinkhorn-Knopp 문제“다. 그래서 같은 행/열 교대 정규화 구조를 그대로 적용할 수 있다.

$$ u^{(l+1)} = r \oslash (K v^{(l)}), \qquad v^{(l+1)} = c \oslash (K^{\top} u^{(l+1)}) $$

(\(\oslash\)는 원소별 나눗셈, \(v^{(0)} = \mathbf{1}\)로 초기화.)

import numpy as np

def sinkhorn_ot(M: np.ndarray, r: np.ndarray, c: np.ndarray,
                 lam: float = 1.0, n_iter: int = 50, eps: float = 1e-12) -> np.ndarray:
    K = np.exp(-lam * M)
    v = np.ones_like(c)
    for _ in range(n_iter):
        u = r / (K @ v).clip(min=eps)
        v = c / (K.T @ u).clip(min=eps)
    return np.diag(u) @ K @ np.diag(v)

r = c = 1_n(모든 marginal이 1)이고 K = A(cost/entropy 변환 없이 원래 행렬을 그대로 씀)로 두면 이 함수는 위의 sinkhorn_knopp와 동일한 문제로 퇴화한다. 즉 고전 버전은 OT 버전의 특수한 경우가 아니라, OT 버전이 고전 버전을 “비용 행렬로부터 유도된 커널"과 “임의의 marginal"로 일반화한 것이라고 보는 게 인과관계상 정확하다(고전 버전이 1967년으로 더 먼저다).

실무적으로 이 방식이 유용한 이유:

  • 행렬-벡터 곱과 원소별 연산만 쓰기 때문에 GPU 병렬화가 쉽고, LP 대비 \(O(n^2)\) 수준으로 계산량이 줄어든다.
  • 모든 연산이 미분 가능해서, Wasserstein distance 자체를 신경망의 손실 함수로 사용할 수 있다(SwAV, SuperGlue 등에서 실제로 사용).
  • \(\lambda\)가 커지면 \(K\)의 값이 0에 가까워져 수치적으로 불안정해지는데, 이는 log-domain 계산으로 완화한다.

3. EPTQ Algorithm 1: 같은 구조, 다른 목적

EPTQ 논문 4.2절은 가중치 행렬 \(W\)를 다음처럼 분해한다.

$$ W = W' \odot (g h^{\top}) $$

목표는 \(W'\)의 모든 행/열의 L1 노름(평균 절댓값)이 1(unity)로 수렴하도록 \(g\)(행 스케일), \(h\)(열 스케일)를 찾는 것이다(논문 원문: “the mean absolute value of every row and column in \(W'\) converges to unity”). 즉 고전 Sinkhorn-Knopp이 “행/열 합이 1"을 목표로 하듯, EPTQ는 “행/열 평균 절댓값이 1"을 목표로 한다 — 기준이 합에서 평균으로 바뀐 것이지, 목표 상수 자체를 고정하지 않는 것은 아니다. 논문은 이 문제가 “절댓값 행렬 \(|W|\)에 대해 doubly stochastic matrix를 구하는 문제와 수학적으로 동치"라고 말하고, Sinkhorn-Knopp의 반복 구조를 그대로 재사용한다.

import torch

def iterative_weight_scaling(W: torch.Tensor, n_iter: int = 5, eps: float = 1e-8):
    d_row, d_col = W.shape
    g = torch.ones(d_row)
    h = torch.ones(d_col)
    W_abs = W.abs()

    for _ in range(n_iter):
        g = (W_abs / h.clamp_min(eps)).sum(dim=1) / d_col   # 행 정규화
        h = (W_abs.T / g.clamp_min(eps)).sum(dim=1) / d_row  # 열 정규화

    W_prime = W / (g.unsqueeze(1) * h.unsqueeze(0)).clamp_min(eps)
    return W_prime, g, h

(위 코드는 이 블로그의 EPTQ 논문 노트에서 이미 텍스트만 보고 비공식으로 재구성해둔 것과 동일하며, 공식 구현이 아니다.)

세 버전을 나란히 놓고 비교하면 무엇이 같고 다른지가 뚜렷해진다.

고전 Sinkhorn-Knopp (1967) OT/entropic (Cuturi, 2013) EPTQ Algorithm 1
대상 행렬 임의의 양수 행렬 \(A\) 비용행렬에서 유도한 Gibbs kernel \(K = e^{-\lambda M}\) 가중치의 절댓값 행렬 \(\lvert W \rvert\)
정규화 기준 행/열의 합(sum) 행/열의 합, 단 목표값이 \(r, c\)로 일반화 행/열의 L1 평균(mean)
목표 상수 1 (행/열 합) \(r, c\) (지정된 marginal 분포) 1 (행/열 평균 절댓값, unity)
엔트로피 정규화 없음 있음 (\(\lambda H(P)\)) 없음
풀려는 문제 행렬 균형화 그 자체 최적수송(Wasserstein distance) 근사 양자화 전 가중치 분산 불균형 제거
수렴 속도 선형 수렴 선형 수렴 (contraction mapping) 논문 보고: 보통 5회 미만

정리하면, EPTQ는 OT나 entropic regularization과는 무관하고, 행 정규화 ↔ 열 정규화를 번갈아 반복한다는 Sinkhorn-Knopp의 알고리즘적 골격만 빌려서 “행/열 합=1"이 아니라 “행/열 평균 절댓값=1"이라는, 기준만 다른 제약에 적용한 것이다. 논문이 “Sinkhorn-Knopp 알고리즘을 (재)적용한다"고 쓴 건 이런 의미다.

헷갈렸던 부분 / 다시 볼 것

  • 처음에는 EPTQ가 Cuturi의 OT 버전(엔트로피 정규화, cost matrix)을 그대로 쓰는 줄 알았는데, 실제로는 cost matrix나 entropy 항이 전혀 등장하지 않는다. “Sinkhorn-Knopp"이라는 이름이 가리키는 건 목적함수가 아니라 ‘행/열 교대 정규화 반복’이라는 알고리즘 구조 자체라는 걸 명확히 할 것.
  • iterative_weight_scaling의 업데이트가 sum이 아니라 sum(...)/d_col (즉 평균)인 이유: 목표 상수 자체는 고전 버전과 마찬가지로 1로 고정되어 있지만(unity로 수렴), 정규화 기준이 “합"이 아니라 “평균"이라서 나눠주는 분모가 원소 개수(d_col, d_row)로 바뀐 것뿐이다. 처음에는 이걸 “목표 상수가 없는 상대적 균일화"로 오해했었는데, 논문 원문(“converges to unity”)을 다시 보고 정정함. 다음에 실제로 두 버전을 같은 입력으로 돌려서 고정점(fixed point)이 어떻게 다른지 수치로 비교해볼 것.
  • \((g, h)\)의 유일성: \(g h^{\top}\)이 의미 있는 값이지 \(g, h\) 개별 값은 \((cg, h/c)\) 형태의 scalar 자유도를 갖는다는 점을 짚고 넘어갈 것 (아래 확인 질문 3번).

확인 질문

고전 Sinkhorn-Knopp(1967)과 Cuturi의 OT 버전(2013)은 정확히 뭐가 다른가?

알고리즘의 반복 구조(행 정규화 ↔ 열 정규화 교대)는 동일하다. 차이는 무엇에 적용하고 무엇을 목표로 하는가다. 고전 버전은 주어진 양수 행렬 자체를 직접 정규화해서 행/열 합이 1인 doubly stochastic matrix를 만드는 것이 목적이다. Cuturi의 OT 버전은 최적수송 문제에 엔트로피 정규화 항을 추가한 뒤, 그 해가 \(\mathrm{diag}(u) K \mathrm{diag}(v)\) 형태(\(K\)는 비용 행렬에서 유도된 Gibbs kernel)를 갖는다는 걸 증명하고, 그 스케일 벡터 \(u, v\)를 구하는 데 같은 반복 구조를 재사용한 것이다. 즉 고전 버전은 “행렬을 대상으로 한 목적 자체"이고, OT 버전은 “최적수송 문제를 풀기 위한 도구로 재사용"한 것이라는 관계다.

EPTQ에서 L2가 아니라 L1 노름을 정규화 기준으로 쓰는 이유는 Sinkhorn-Knopp와 무슨 관계가 있나?

Sinkhorn-Knopp 자체는 “행 정규화 ↔ 열 정규화 반복"이라는 구조일 뿐, 정규화 기준이 합이든 L1이든 L2든 상관없이 적용 가능한 뼈대다. EPTQ는 이 뼈대를 절댓값 행렬의 L1 평균에 적용했는데, 만약 L2를 썼다면 소수의 매우 큰 outlier 가중치가 스케일 계산 자체를 왜곡했을 것이다. EPTQ에서는 outlier 가중치를 스케일 정규화가 아니라 별도 메커니즘(Adaptive Critical Weight Preservation)이 처리하도록 역할을 분리해뒀기 때문에, 정규화 자체는 outlier에 덜 민감한 L1을 쓰는 것이 설계 의도에 맞다.

Iterative Weight Scaling이 수렴하면 g, h는 유일하게 결정되는가?

아니다. 최종적으로 의미 있는 값은 \(g h^{\top}\)(각 원소의 곱)이지 \(g\), \(h\) 개별 벡터가 아니다. 임의의 스칼라 \(c\)에 대해 \((cg,\, h/c)\)도 똑같은 \(g h^{\top}\)를 만들어내므로 개별 벡터에는 scalar 자유도가 남는다. Doubly stochastic scaling 문제 일반에서 스케일링 대각행렬 쌍이 유일하지 않고 이런 자유도를 갖는 것과 같은 현상이다.
