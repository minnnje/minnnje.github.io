Example: CUDA 메모리 계층 구조 정리

Subject GPU Programming
2026. 7. 18 · 1분 읽기
  • Cuda
  • Gpu
  • Memory

오늘 배운 것

Global / Shared / Register 메모리의 속도-용량 트레이드오프와, shared memory를 활용한 타일링(tiling)으로 global memory 접근 횟수를 줄이는 방법 (예시 콘텐츠).

왜 중요한가 (맥락/동기)

LLM 추론 커널을 최적화하려면 메모리 대역폭이 병목인지 연산량이 병목인지부터 구분해야 하고, 이때 CUDA 메모리 계층에 대한 이해가 기본 전제가 됨.

핵심 개념 정리

  • Register: 스레드별 전용, 가장 빠름, 용량 매우 작음
  • Shared memory: 블록 내 스레드가 공유, register보다 느리지만 global보다 훨씬 빠름
  • Global memory: 용량은 크지만 지연시간이 김, coalesced access가 중요

헷갈렸던 부분 / 다시 볼 것

  • Bank conflict가 정확히 언제 발생하는지 다시 정리할 것
  • Shared memory 타일 크기와 occupancy 사이의 트레이드오프

확인 질문

Coalesced memory access란?

같은 warp 내 스레드들이 연속된 global memory 주소에 접근할 때, 하드웨어가 이를 하나의 트랜잭션으로 묶어 처리하는 것. 접근 패턴이 흩어져 있으면 여러 번의 트랜잭션으로 쪼개져 대역폭 효율이 떨어진다.
